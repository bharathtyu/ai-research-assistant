• ReLU is a non-linear operation that involves units that use the rectifier. It is an element- wise 
operation which means that it is applied per pixel, reconstituting all the negative values by 
zero in the feature map. To understand how ReLU operates, we assume that in the literature 
for neural networks there is a neuron input given as x and from that the rectifier is defined as 
f(x)= max(0,x).
